2) How do you add an index. Why would you add an index to an entity.

We add an index to improve read performance for frequently accessed fields. Indexes allow the database to locate rows faster without scanning the entire table, which improves the speed of searches, joins, and lookups.

Loadable properties improve performance by delaying the loading of large or rarely used entity fields until they are actually accessed. This reduces initial query size, memory usage, and speeds up screen load times.

10) What is the difference between Bind and Issue.

Bind:
Legal commitment to provide insurance.
UW approves the quote.
Premium and terms become final.
Policy is not active yet; coverage does not start.

Issue:
After bind, the system generates the actual policy.
Coverage starts at the effective date.
Policy number is assigned (if not earlier).

Bind commits the insurer to issue the policy; Issue officially activates the policy and coverage.

17) What is current bundle. When do we use current and new bundle ?

Current bundle:
Every server-side action (PCF action, rule execution, plugin call, etc.) already runs inside a current bundle.
When you modify data on the screen or update an entity during a job: You always use the current bundle.

New bundle:
You create a new bundle only when you need an independent transaction, separate from the current work.
Example: Background processing inside a batch process.


18) Situation - What if we add a new data field in a pcf file and we are collecting the new data, so do we create a new bundle or a current bundle to commit the data ?
We use the Current Bundle.
Reason:
The data entered through the PCF belongs to the current job (Submission, Change, etc.)
Guidewire automatically binds UI updates to the current bundle

20) Can you explain the messaging framework in guidewire.
Guidewire Messaging Framework is used for asynchronous integration with external systems.

1. Event
A business event triggered by entity changes.
Example: Policy bound, claim created, check issued.

2. Event Fired
When a monitored entity changes (Insert/Update/Delete), Guidewire “fires” an event.

3. Message
A row created in the message table.
Contains event name + entity key + XML/JSON payload.

4. Destination
Configuration that defines:
   Where to send the message
   What retry rules apply
   Which plugin handles the message

5. Transport
How the message is delivered: SOAP and REST

6. Messaging Plugins
Example: IMessagingPlugin
Converts entity data → XML/JSON → sends to target system.


7. Acknowledge / Retry / Error Handling
If the external system responds: Ack
If no response or error

36) How to trigger uw issue using gosu codes?


function raiseUnderAgeIssue(policyPeriod : PolicyPeriod, driver : Driver) {
  if (driver.Age >= 18) return

  // 1) Check if an open UW issue with same key already exists
  var existing = policyPeriod.UWIssues
    .where(\ i -> i.IssueKey == "DriverUnderAge" and i.Status == UWIssueStatus.TC_OPEN)
    .first()
  if (existing != null) return

  // 2) Create new issue in the current (writable) bundle
  var b = Transaction.getCurrent()  // type: gw.transaction.Bundle
  var issue = new UWIssue(b)

  issue.PolicyPeriod     = policyPeriod
  issue.IssueKey         = "DriverUnderAge"                // Business key
  issue.UWIssueType      = UWIssueType.TC_RULE             // Or other appropriate type
  issue.Severity         = UWIssueSeverity.TC_BLOCKING     // BLOCKING / WARNING
  issue.Status           = UWIssueStatus.TC_OPEN
  issue.OwnerRole        = UWIssueOwnerRole.TC_UNDERWRITER
  issue.ShortDescription = "Driver younger than 18"
  issue.LongDescription  = "Minimum allowed driver age is 18; please review or decline."

  policyPeriod.addToUWIssues(issue)

  // 3) (Usually the framework commits; else explicitly:)
  // Transaction.commit()
}

59) Code for fetching an exposure using claim number of a claim using an Iterator(loop)- code snippet for iterating a collection- He meant to ask that how will you index a variable in the for loop

function printExposuresWithIterator(claimNumber : String) {
  var claim = Query.make(Claim)
    .compare("ClaimNumber", Equals, claimNumber)
    .select().first()

  if (claim == null) {
    print("No claim found for claim number: " + claimNumber)
    return
  }

  var exposures = claim.Exposures
  if (exposures == null or exposures.Empty) {
    print("No exposures on claim " + claimNumber)
    return
  }

  var it = exposures.iterator()
  var idx = 0
  while (it.hasNext()) {
    var exp = it.next()
    print("Index=" + idx
      + ", ExposureID=" + exp.ID
      + ", Coverage=" + exp.Coverage?.PatternCode
      + ", ReserveStatus=" + exp.ReserveLineSet?.Status?.Code)
    idx += 1
  }
}

63) Why we do NOT call commit inside runWithNewBundle()?

We don’t commit inside runWithNewBundle() because Guidewire automatically commits the bundle if the callback runs successfully. If an exception occurs, the framework rolls back. Manually committing would interfere with Guidewire’s transaction management.

67) What is Product Model ?

The Product Model in PolicyCenter is the configuration framework that defines an insurance product—its lines, coverables, coverages, coverage terms, conditions, exclusions, modifiers, question sets, and availability/eligibility rules.
